# Student Result Calculator

A simple Python program that calculates a student's total marks, percentage, grade, and pass/fail status based on marks entered for six subjects.

Features
Accepts student name and marks for:
Telugu
Hindi
English
Maths
Science
Social
Checks pass/fail status.
Calculates total marks.
Calculates percentage.
Assigns grades based on percentage.
Grade System
Percentage	Grade
90% and above	A+
80% - 89%	A
70% - 79%	B+
60% - 69%	B
50% - 59%	C
Below 50%	D
Pass Criteria

A student is considered Failed if marks in any subject are less than 35.

How to Run
Install Python on your system.
Save the code in a file named student_result.py.
Open a terminal or command prompt.

Run the program:
python student_result.py

Sample Input
Enter student name: Ram
Enter telugu marks: 85
Enter hindi marks: 78
Enter english marks: 90
Enter maths marks: 88
Enter science marks: 92
Enter social marks: 80
Sample Output
Percentage is: 85.5
A grade
Result: Passed
